# ASK Desktop

ASK Desktop ist die Windows-App der TF Bern für ASK: Man beschreibt einen Auftrag, und das Sprachmodell arbeitet selbständig in einem Ordner auf dem Laptop.

Hier liegen nur die fertigen Versionen zum Herunterladen.

**[Zur Download-Seite](https://kiyeager.github.io/ASK-Releases/)**: neueste Version, was neu ist, und eine Anleitung mit Bildern.

## Installieren

1. [ASK-Setup.exe herunterladen](https://github.com/KIYeager/ASK-Releases/releases/latest/download/ASK-Setup.exe)
2. Doppelklicken. Die Installation braucht keine Admin-Rechte und stellt keine Fragen.
3. Warnt Windows («Der Computer wurde durch Windows geschützt»): «Weitere Informationen», dann «Trotzdem ausführen».

Danach aktualisiert sich ASK selbst: Gibt es eine neue Version, fragt die App, ob sie sie installieren soll.

## Ohne Installation

[ASK.exe herunterladen](https://github.com/KIYeager/ASK-Releases/releases/latest/download/ASK.exe) und starten, zum Beispiel auf einem Laptop, auf dem man nichts installieren darf. Diese Variante aktualisiert sich nicht selbst; sie meldet eine neue Version, und man lädt sie hier wieder herunter.

## Alle Versionen

Unter [Releases](https://github.com/KIYeager/ASK-Releases/releases). Versionen mit «Pre-release» sind Beta-Versionen zum Testen.

Die Datei `docs/index.html` ist die Download-Seite. Sie wird bei jeder neuen Version automatisch ersetzt; Änderungen von Hand gehen dabei verloren.
