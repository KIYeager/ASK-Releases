ASK für Windows

Man beschreibt einen Auftrag, und das Sprachmodell arbeitet selbständig in einem Ordner auf dem Laptop.

ASK läuft nur auf Windows. Diese Seite auf dem Windows-Laptop öffnen und dort herunterladen.

HerunterladenASK-Setup.exe · 90 MB Version 0.3.15 · 27. November 2026 · für Windows

Ohne Installation, zum Beispiel wenn man auf dem Laptop nichts installieren darf: ASK.exe herunterladen (92 MB). Diese Variante aktualisiert sich nicht selbst; sie meldet eine neue Version, und man lädt sie hier wieder herunter.

So geht’s

  1. Herunterladen

    Auf den blauen Knopf klicken. Die Datei landet im Ordner «Downloads».

  2. Doppelklicken

    ASK-Setup.exe öffnen. Die Installation braucht keine Admin-Rechte und stellt keine Fragen.

  3. Warnt Windows? Trotzdem ausführen.

    Beim ersten Mal erscheint oft «Der Computer wurde durch Windows geschützt». Das ist normal, weil ASK nicht bei Microsoft registriert ist.

  4. Fertig

    ASK startet und steht im Startmenü und auf dem Desktop. Gibt es eine neue Version, fragt ASK selbst, ob es sie installieren soll.
